# 站点管理、备份、凭证与通知

### 🔗 站点管理（Hub → 站点）

Hub 模块的**站点**页签将上游中继平台作为一等实体管理。站点代表 New-API、One-API、One-Hub、Done-Hub、Sub2API、AnyRouter、OpenAI、Claude、Gemini 等平台。每个站点渲染为多账号卡片，内联展示余额、同步状态和签到状态，替代了此前的多页签 Hub 布局。

**功能特性：**

- 每个站点支持多账号，凭证类型包括用户名/密码、access_token 或 api_key
- 按可配置间隔自动同步渠道、令牌和模型
- 自动签到，支持可配置间隔和随机时间窗口（按账号开关）
- 按账号的内联操作：同步、签到、启用/停用、编辑、删除
- 按站点的操作：置顶、归档 / 恢复、批量编辑（启用 / 停用 / 删除）、导入
- **投射渠道**：从站点账号分组自动创建本地 Octopus 渠道，支持按分组的 Key 管理、模型路由和历史追踪（在**站点渠道**页签查看）
- 按模型自动推断路由类型（openai_chat、openai_response、anthropic、gemini、volcengine、embedding）
- 支持手动添加 / 删除模型和路由类型覆盖
- 支持从 AllAPIHub 和 MetAPI 格式批量导入（上传文件或粘贴 JSON）
- 代理池集成，支持按站点、按账号和按渠道的代理选择
- 归档站点（保留账号/Key/模型，下线投射渠道），可从归档列表恢复
- **自动化**页签合并自动同步和自动签到间隔配置

### ☁️ WebDAV 云备份

基于 WebDAV 的自动云备份，提供完整生命周期管理：

- 可配置基础 URL、凭证、远程路径、自动备份间隔（默认 6 小时）和最大备份保留数
- 启用前连接测试
- 手动触发备份
- 远程备份文件列表（含大小信息）
- 从任意远程备份一键恢复
- 删除远程备份
- 作为设置页独立卡片提供

**备份内容与保密提示：**

备份文件是数据库的 JSON dump，与「设置 → Backup」导出同格式。始终包含核心表（渠道、Key、分组、API Key、设置、告警、通知、运行时状态）、站点相关表，以及 Hub 表 `remote_sites`、`balance_snapshots`、`check_in_records`、`api_credential_profiles`、`site_announcements`、`remote_site_tokens`。转发日志和审计日志（勾选「包含日志」时）与统计数据（勾选「包含统计」时）仅在勾选后导出。号池相关表和 Hub 的用量历史记录（`remote_usage_records`）不在备份范围内。

> ⚠️ **保密提示**：当前 dump 格式（v2）中，敏感字段——渠道 Key、API Key、站点访问令牌 / 密码、凭证 API Key——会以**明文**导出（这样备份才能在另一实例上正确恢复；导入时会按目标实例的密钥重新加密）。拿到备份文件即拿到全部有效凭据：请加密存储 / 限制访问，切勿提交到版本库或对外分享。

### 🔑 API 凭证档案与 CLI 导出

可复用的 API 凭证档案存储 Base URL + API Key 对，方便快速访问：

- 健康探测类型：`text_gen`、`models_list`、`tool_calling`、`structured_output`
- 按凭证健康状态追踪
- 通过 `security.encryption_key` 加密存储
- 标签和备注用于组织管理

**CLI 配置导出：**

为以下客户端工具生成即用配置片段：

| 工具 | 格式 |
|------|------|
| Claude Code | `~/.claude/settings.json` 环境变量 |
| Codex | `~/.codex/auth.json` 和 `config.toml` 环境变量 |
| Gemini CLI | 环境变量 |
| Cherry Studio | JSON 供应商导入配置 |
| Kilo Code | JSON 设置块 |

### 🚨 通知中心与告警

通知模块是统一中心，聚合系统事件、告警触发和套餐供应商通知，支持严重级别、已读/归档状态、过滤和 SSE 实时推送。告警规则监控系统健康并触发通知：

**告警规则类型：** 错误率（支持可配置作用域——按渠道 / 按分组 / 全局——和滑动窗口评估）、费用阈值、额度超限、渠道下线，以及号池账号异常（任一或指定号池账号持续处于错误状态时触发）。

**通知渠道：**

| 渠道 | 配置项 |
|------|--------|
| Webhook | URL、方法、Header |
| Gotify | 服务地址、应用 Token |
| Email | SMTP 设置、收件人 |
| Telegram | Bot Token、Chat ID |
| 飞书 | Webhook Key |
| 钉钉 | 机器人 Access Token、可选 HMAC-SHA256 签名密钥 |
| 企业微信 | 群机器人 Key |
| ntfy | Topic URL、可选 Access Token |

每条规则的告警状态和历史均会被追踪，支持可配置的评估间隔。

**用量报表：** 支持按日 / 周 / 月调度用量报表，通过已配置的通知渠道送达，并记录报表历史。
